# O.S. - Pagination simulator
Developed project to simulate O.S. pagination using existing theoretical models (FIFO, LRU, OPT and LIFO).

It is a static page: the simulation runs in the browser, in JavaScript. There is no server-side code.

### Run Project Instructions

Serve the project folder with any static server, for example:
```shell
python -m http.server 8000
```

Access the project in the browser
```shell
http://localhost:8000
```

To publish, upload `index.html` and the `assets` folder.
